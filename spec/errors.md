# COMMAND OS CORE v2 — Codes d’erreur

## Erreurs

- `E101 UNKNOWN_COMMAND` — commande inconnue.
- `E102 INVALID_COMMAND_SYNTAX` — syntaxe de commande invalide.
- `E103 MISSING_REQUIRED_TARGET` — cible indispensable introuvable.
- `E104 INVALID_PIPELINE` — pipeline non interprétable.

## Avertissements

- `W201 UNKNOWN_OPTION` — modificateur/méthode inconnu.
- `W202 CONFLICTING_DEPTH` — plusieurs profondeurs explicites ; la dernière gagne.
- `W203 CONTEXT_REQUIRED` — contexte nécessaire pour résoudre une commande.
- `W204 CAPABILITY_UNAVAILABLE` — capacité/outillage demandé indisponible.
- `W205 ALIAS_EXPANDED` — alias converti vers sa forme canonique.
- `W206 MACRO_EXPANDED` — macro développée vers son pipeline canonique.

## Information

- `I301 PIPELINE_NORMALIZED` — ordre non strict normalisé.
- `I302 EXPERTS_ROUTED` — experts sélectionnés par le routeur.
